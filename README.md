# esp32-x11
X11 client implementation for ESP32 Arduino platform.

## Overview
This project provides a functional X11 client library (`Xlib.h`, `Xlib.cpp`) that allows an ESP32 to connect to an X11 server over WiFi and perform basic windowing and drawing operations. It implements the X11 wire protocol directly, removing the need for a full Xlib library on the embedded device.

## Features
- Direct X11 wire protocol implementation.
- Connection handshake with byte-order negotiation.
- parsing of server information and screens.
- Window creation, naming, and mapping.
- Text drawing using `XDrawString` with font support.
- Event loop for handling `Expose` and `KeyPress` events.

## Components
- `Xlib.h` / `Xlib.cpp`: Custom library implementing the X11 protocol.
- `esp32_x11.ino`: Example Arduino sketch showing how to use the library.
- `mock_arduino/`: headers for simulating the Arduino environment on Linux for testing.
- `main.cpp`: Test runner for the Linux simulation.
- `make_png.py`: Utility to convert raw X11 pixel data to PNG images.

## Testing and Screenshots
The implementation has been verified on Linux against an `Xvfb` (Virtual Framebuffer) server. The test suite simulates an ESP32 connecting to the server, creating a 200x100 window, and drawing "Hello world!".

### Running the Test Suite
1. Ensure you have `g++`, `Xvfb`, and `python3` installed.
2. Start the virtual X server:
   ```bash
   Xvfb :1 -ac -listen tcp -screen 0 800x600x24 &
   ```
3. Compile the mock client:
   ```bash
   g++ -I. -Imock_arduino Xlib.cpp main.cpp -o x11_snapshot_test
   ```
4. Run the test:
   ```bash
   DISPLAY=:1 ./x11_snapshot_test
   ```
5. Check `screenshot.png` for the result.
