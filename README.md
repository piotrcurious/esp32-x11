# esp32-x11
X11 client implementation for ESP32 Arduino platform.

## Overview
This project provides a functional X11 client library (`Xlib.h`, `Xlib.cpp`) that allows an ESP32 to connect to an X11 server over WiFi and perform basic windowing and drawing operations.

## Features
- X11 wire protocol implementation over TCP.
- Connection handshake and screen information parsing.
- Window creation and mapping.
- Centered text drawing using `XDrawString`.
- Event loop for handling `Expose` and `KeyPress` events.

## Components
- `Xlib.h` / `Xlib.cpp`: Custom Xlib-like library implementing the X11 protocol.
- `esp32_x11.ino`: Example Arduino sketch.
- `mock_arduino/`: (For testing) Mock headers to run the code on Linux.
- `make_png.py`: Utility to convert raw pixel data to PNG snapshots.

## Testing and Screenshots
The implementation was verified against an `Xvfb` server on Linux using a mock Arduino environment.

To run the test suite and generate a screenshot:
1. Start Xvfb: `Xvfb :1 -ac -listen tcp -screen 0 800x600x24 &`
2. Compile the mock client: `g++ -I. -Imock_arduino Xlib.cpp main.cpp -o x11_snapshot_test`
3. Run the test: `DISPLAY=:1 ./x11_snapshot_test`
